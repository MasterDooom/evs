# EVS CAT-II Rapid Revision

A local, exam-focused Environmental Science CAT-II revision site built from the supplied course material.

## Run locally

Clone:

```bash
git clone git@github.com:MasterDooom/evs.git
cd evs
```

Then either open `index.html` directly or run:

```bash
python -m http.server 5173
```

Open `http://localhost:5173`.

## Included

- 26 course topics condensed into high-yield exam notes
- Definitions + key facts + MCQ traps
- Visual recall flowcharts
- Search across the syllabus
- Local revision checklist/progress
- 60+ exam-style MCQs and a random 30-question test
- Responsive desktop/mobile UI

Content is based on the lecture PDFs supplied for this CAT-II revision session.
